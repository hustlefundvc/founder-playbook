# Changelog

All notable changes to the `forwardable-intro` skill are documented here. This skill follows [semantic versioning](https://semver.org/).

## v1.1.0 — 2026-06-10

### Added
- **"Why now" component.** New coaching section and an optional blurb line for the technological, regulatory, or cultural shift that makes this the moment for the company. Included only when it's real and specific — never manufactured.

### Changed
- **Paste-friendly formatting.** Reflowed every template and the worked example so each paragraph is a single unwrapped line. Added an explicit output rule: no manual line breaks inside a paragraph, blank lines between blocks only. Fixes the choppy formatting that showed up when pasting into Superhuman and Gmail.

## v1.0.0 — 2026-06-10

### Added
- Initial release: two-layer forwardable intro (cover note + forwardable blurb), component coaching, single-investor and list support, and a worked example.
